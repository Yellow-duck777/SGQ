# SGQ - Sistema de Gestão da Qualidade

Sistema web para gerenciamento dos processos de qualidade.

## Processos iniciais

- Reclamação de Cliente
- Não Conformidade
- Recolhimento / Recall de Produto

## Objetivo

Centralizar registros, investigações, ações, aprovações,
evidências e rastreabilidade dos processos de qualidade.

## Tecnologias previstas

- C#
- ASP.NET Core
- Entity Framework Core
- PostgreSQL
- HTML
- CSS
- JavaScript
- Git
- GitHub
- Codex

## Status

O projeto está em fase de consolidação de requisitos e construção da fundação técnica. A aplicação ASP.NET Core, a autenticação e os cadastros básicos iniciais já foram iniciados.

Os requisitos e decisões de negócio estão documentados em [docs/02-requisitos.md](docs/02-requisitos.md).
