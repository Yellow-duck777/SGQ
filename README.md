# SGQ - Sistema de Gestão da Qualidade

Sistema web para gerenciamento dos processos de qualidade.

## Processos iniciais

- Reclamação de Cliente
- Não Conformidade
- Recolhimento / Recall de Produto

## Objetivo

Centralizar registros, investigações, ações, aprovações,
evidências e rastreabilidade dos processos de qualidade.

## Tecnologias previstas

- C#
- ASP.NET Core
- Entity Framework Core
- PostgreSQL
- HTML
- CSS
- JavaScript
- Git
- GitHub
- Codex
